# 台灣地震 3D 互動圖

把地表掀開，看 1990 年起的地震點如何排列出台灣地底的板塊結構。

製作：101事務所

## 想直接操作

打開網站就能玩，電腦或手機都可以：

**[打開台灣地震 3D 互動圖](https://tbdavid2019.github.io/taiwan-earthquake-site/)**

- 拖曳：旋轉視角
- 滾輪或雙指縮放：放大縮小
- 點一下地震點：查看該筆原始資料

## 資料來源

- 地震資料：交通部中央氣象署地震目錄（1990 年起，規模 3.0 以上），政府資料開放授權
- 地形資料：NOAA ETOPO 2022 / GEBCO（15 弧秒網格），公有領域（Public Domain）
- 海岸線圖資：g0v 社群台灣邊界圖資，政府資料開放授權

地表高度放大 5 倍，地震深度為真實比例。

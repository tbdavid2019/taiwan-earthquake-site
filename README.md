# 台灣地震 3D 互動圖

把地表掀開，看 1990 年起的地震點如何排列出台灣地底的板塊結構。

製作：101事務所

## 想直接操作

打開網站就能玩，電腦或手機都可以：

**[打開台灣地震 3D 互動圖](https://tbdavid2019.github.io/taiwan-earthquake-site/)**

- 拖曳：旋轉視角
- 滾輪或雙指縮放：放大縮小
- 點一下地震點：查看該筆原始資料

## 資料來源

- 地震資料：交通部中央氣象署地震目錄（1990 年起，規模 3.0 以上），政府資料開放授權
- 地形資料：NOAA ETOPO 2022 / GEBCO（15 弧秒網格），公有領域（Public Domain）
- 海岸線圖資：g0v 社群台灣邊界圖資，政府資料開放授權

地表高度放大 5 倍，地震深度為真實比例。

## 資料更新與部署

GitHub Actions 每天檢查中央氣象署的歷史年度目錄與本年度目錄；資料有變更時重建 CSV 並提交。氣象署本年度目錄每月更新，通常只涵蓋至前一個月，並非即時地震資料。畫面顯示官方發布日期與本年度目錄的涵蓋截止時間。

手動更新：執行 `python3 scripts/update_earthquakes.py`，或在 GitHub Actions 手動執行 **Update and deploy earthquake site**。腳本使用政府資料開放平臺公布的公開存取參數，不需設定個人金鑰。

部署前請在 GitHub 儲存庫的 **Settings → Pages → Build and deployment** 將 Source 設為 **GitHub Actions**，並允許 Actions 寫入儲存庫。推送預設分支或排程更新成功後，工作流程會發布網站。
